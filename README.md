# **Hangman Game**
Description

This is a simple text-based Hangman Game developed in Python. The player has to guess a hidden word one letter at a time. The game provides limited chances to guess the correct word.

# **Features**

- Random word selection
- User-friendly interface
- Limited attempts
- Win and lose conditions
- Input validation

# **Technologies Used**

- Python

# **How to Run**

1. Open the project in VS Code.
2. Run the Python file.
3. Enter letters to guess the hidden word.
4. Continue until you win or run out of attempts.

# **Learning Outcomes**

- Python basics
- Loops and conditions
- String handling
- Lists and functions
